## 2. 数据与真值：枚举，不抽真实图像

建立结构化的抽象世界。每组固定两个不同中性实体 ID：目标 `t` 与干扰对象 `d`。分别枚举两帧中的存在状态：`(t_A,t_B,d_A,d_B) ∈ {0,1}^4`，共 **16 组**。两帧另有不同背景标识，使 AB 即使对象状态相同也不必是完全相同的输入。AA/BB 则逐字段复制同一帧，输入身份相同。

每组生成 AB、BA、AA、BB 四种条件；各条件再生成两个提示版本：版本 0 中 AB/AA/BB 的顺序标记为 ORIGINAL、BA 为 REVERSED；版本 1 仅将 ORIGINAL/REVERSED 对调。任务要求始终按**实际输入先后顺序**回答目标的存在性方向，该非任务必需的标记不改变实体或实际输入顺序。共 **16×4×2=128 条**，按组汇总，不能称为 128 个独立样本。

| 实际先帧存在性 | 后帧存在性 | 该条件正确答案 |
|---|---|---|
| 0 | 1 | APPEAR |
| 1 | 0 | DISAPPEAR |
| 0 | 0 | NO_EXISTENCE_CHANGE |
| 1 | 1 | NO_EXISTENCE_CHANGE |

这里的无变化只指**目标存在性不变**，不代表整幅场景没有其他变化。对象身份由生成器固定，没有遥感对象尺度歧义。两侧状态、答案与字段定义都公开；这是评分协议的有限域诊断，不是视觉数据集或独立报告样本。

`UNKNOWN`、缺记录、非法输出均独立记账；模型式弃答不能被删出分母。参考真值在本合成域中全部已知，不把“参考未决”与“策略弃答”合并。

## 3. 固定策略与三类互补读数

在运行前固定以下六个确定性策略；记录各自实际能读取的字段，禁止将评分目标偷偷传给捷径策略。

| 策略 | 可读取信息与规则 | 用途 |
|---|---|---|
| ORACLE | 读取目标在实际两帧中的存在性，按上表返回 | 合成域正确策略，用作评分核对；不是实测模型。 |
| CONST_NULL | 对任何输入返回 NO_EXISTENCE_CHANGE | 检查恒判空及变化样本分母。 |
| CONST_APPEAR | 对任何输入返回 APPEAR | 检查恒报方向与同图条件。 |
| SLOT_ID | 只读帧身份与顺序提示；同帧返回无变化，否则提示为原序答 APPEAR、逆序答 DISAPPEAR | 检查“输入身份＋提示”能否伪通过关系门槛；不得读对象状态。 |
| INVERT_TARGET | 读取目标状态，对 APPEAR/DISAPPEAR 互换，无变化保持 | 检查两次一起答错但保持换序关系。 |
| DISTRACTOR | 只按干扰对象两帧存在性返回方向 | 检查关系正确却绑定错对象。 |

**R0：关系门槛。** 在目标确有存在性变化的 8 个基础组上，两个顺序均给方向回答且 BA 是 AB 的反向；分别检查两种提示版本。AA/BB 在全部 16 组均须判存在性不变。所有指定格完整通过才称 R0 通过；不以弃答或缺记录缩小分母。

**R1：完整合同。** 在全部指定格上分别报告：

- MFT：各条件对其自己的正确目标的准确计数，类别×条件×提示版本分解，以及 AB/BA 同时正确的组数。
- DIR：R0 的换序关系与有效回答覆盖；关系成立和答案正确分列。
- INV：同一组同一实际输入条件的两个提示版本应给相同任务答案；AA/BB 的判空单列，避免漏报某类行为。
- 全量错误、UNKNOWN、缺记录和非法输出。禁止使用“解析成功率”代替任务准确率。

完整合同通过定义为：全量 MFT、DIR、INV 及 AA/BB 指定格均完整且正确。每策略 MFT 分母 128；AB/BA 联合正确分母 16 组×2 提示版本=32 个组内配对；DIR 变化子集分母 8 组×2=16 个组内配对；提示 INV 分母 16 组×4 条件=64 个组内配对；AA/BB 判空分母 16×2 条件×2 版本=64 条。各提示版本仍分别报告。这是**生成规则已知的诊断门槛**，不能直接用作真实模型的 100% 能力要求。两套合同都计算，不把它们压成一个无法解释的加权总分。

唯一主读数：**固定的 5 个非 ORACLE 策略中，有多少通过 R0、同时未通过 R1**；逐策略给反例组与完整输入/输出。这个数量是所列反例策略的描述，不能估计真实模型中捷径的发生率。辅助读数为六策略的完整仪表表和 R1 漏检清单。

## 4. 变量、资源与边界

| 类型 | 本周固定内容 |
